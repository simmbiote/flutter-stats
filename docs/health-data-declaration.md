# Health Connect data declaration draft

This document is an implementation checklist for the store submission and should be reviewed by the release owner.

- [ ] Health Connect is declared as a read-only integration.
- [ ] Activity, vitals, sleep, and body-measurement permissions are listed accurately.
- [ ] Background read permission and deferred execution behavior are explained.
- [ ] The app does not declare Health Connect write access.
- [ ] Privacy policy explains source handling, Samsung Health visibility, encryption, retention, and deletion.
- [ ] Data deletion/support instructions are published.
- [ ] A staging API and synthetic test records are used for submission validation.
