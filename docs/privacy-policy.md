# Privacy policy draft

Flutter Stats reads selected Health Connect categories only after the user grants read permission. It uses those records to send the user’s configured installation’s data to the receiving service.

The app is read-only. It does not write to Health Connect. Pending health payloads are encrypted on the device and removed after acknowledgement or when the user disconnects. Health values are not shown in the sync status or diagnostic logs.

Samsung Health-origin records are included only when Health Connect exposes them; the app does not independently access the Samsung Health Data SDK in the first release.

The release owner must add the deployment organization, contact details, retention schedule for server-side records, and jurisdiction-specific disclosures before publication.
